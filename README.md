# jjinmap

공공데이터로 "찐"을 증명하는 장소 지도.

## 문제

맛집 지도는 이미 많다. 전부 같은 약점을 공유한다 — **평점과 리뷰는 살 수 있다.**
협찬 블로그, 대가성 리뷰, 부풀린 별점이 걸러지지 않은 채 "맛집"으로 올라온다.

## 접근

공공데이터에는 광고가 섞일 수 없다. 대신 평점도 리뷰도 없다.
그래서 인기를 직접 묻는 대신, **돈으로 살 수 없는 신호**로 대신한다.

작업 가설: **생존기간**.
인허가 데이터의 개업일과 폐업 이력에서 계산되는, 광고비로 조작 불가능한 지표.
"그 자리에서 N년째 안 망한 가게"는 리뷰 한 줄 없이도 공공데이터만으로 증명된다.

## 현재 상태

초기 설정. 아래가 확정되기 전에는 코드를 쓰지 않는다.

- [ ] **핫플 vs 찐** — 방향 확정 (지금 뜨는 곳 / 오래 살아남은 곳. 서로 반대 축이라 하나만 고른다)
- [ ] **공공API 실사** — 어떤 API가 개업일·폐업이력·좌표를 실제로 주는지 `factchk`로 검증
      (TourAPI, 소상공인 상가업소정보, LOCALDATA 인허가, 서울 실시간도시데이터 등 후보)
- [ ] 좌표계 확인 (TM ↔ WGS84), 갱신주기, 일일 호출제한
- [ ] 지역 범위 / 웹·앱 / 지도 렌더러
- [ ] `/re0-plan` 으로 구현 계획 착수
